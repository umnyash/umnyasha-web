Типы коммитов.

  • init — добавить начальные файлы нового проекта.
  • build — всё, что влияет на сборку (webpack, vite, babel, tsconfig, сборочные скрипты).
  • ci — всё, что связано ci/cd.
  • docs — документация (README, комментарии, markdown).
  • chore — рутинные/автоматизированные задачи, такие как обновление зависимостей.
  • feat — добавление новых функциональных возможностей.
  • fix — исправление ошибок и багов.
  • perf — ускорение, оптимизация (мемоизация, уменьшение рендеров, кеши).
  • types — изменения типов TypeScript.
  • refactor — рефакторинг.
  • style — стиль кода, форматирование (пробелы, отступы, prettier, eslint --fix).
  • test — всё, что связано с тестами (добавил, переписал, починил тесты).
  • deprecate — для коммитов, которые делают функциональность устаревшей.
  • release — для коммитов, связанных с выпуском новой версии.
